Support

Free MD Viewer is free and open source. There is no ticket queue — a real person reads these.

Report a bug or ask for a feature

Open an issue on GitHub. It is the fastest route, and it means other people can see the answer. Telling us which version you are on helps — the ? panel in the app shows it.

Things that come up

“Save downloads a copy instead of saving the file”

Writing back to a file you opened needs the File System Access API, which today means Chrome or Edge on the desktop. Everywhere else the browser will not allow it, so Save falls back to a download. This is a browser limit, not a setting we can change.

“My system blocked access to that file”

macOS gates folders such as Desktop, Documents, Downloads and other apps' containers — a Google Drive or Dropbox folder, for instance. Allow the app under System Settings → Privacy & Security → Files & Folders and try again.

“Double-clicking a .md file does not open it here”

Install the app first (Chrome or Edge, from the install icon in the address bar), then right-click a file and choose Open With. If you installed it before and it stopped behaving, uninstalling and reinstalling makes the browser re-read the app's manifest, which is usually the cure.

“It is slow to load the first time”

The full build is a single ~3.7 MB file, because Mermaid and KaTeX are embedded rather than fetched. If you never write diagrams or equations, the lite build is about 287 KB and otherwise identical.

Use it offline or on your own servers

Download index.html and open it from disk, or serve it from anywhere. It needs no backend, no build step and no configuration, and the MIT licence covers commercial use.
