What is Free MD Viewer?

Free MD Viewer is a markdown viewer and editor that runs entirely in your browser. It opens local .md files and renders GitHub-flavored markdown — tables, task lists, footnotes and callouts — along with Mermaid diagrams, LaTeX math and syntax-highlighted code. You can edit with a live preview and save back to the original file, export to HTML, PNG or PDF, and install it so double-clicking a markdown file opens it here. It never uploads your documents, needs no account, and the source is public.

A privacy claim you can check

Most online markdown viewers upload your document to a server to render it. For work documents and private notes, that is a real cost of a “free” tool. This one has no upload path at all.

Questions

Are my files really not uploaded?

Yes. Every library the app needs is embedded in the page itself, so it makes no requests of its own while you use it. Your file is read by the browser from your disk and never sent anywhere. You can confirm this in your browser's network tab, or by saving the page and using it with your connection switched off.

Do I need to install anything or create an account?

No to both. Open the page and drop a file in. You can optionally install it in Chrome or Edge, which lets markdown files open here on double-click and makes it work offline, but that is a convenience rather than a requirement.

Can I edit a file and save it back?

In Chrome and Edge, yes — Save writes straight back to the file you opened, using the File System Access API. Other browsers fall back to a normal download, since they do not support writing to a file you picked.

What markdown does it support?

GitHub-flavored markdown — tables, task lists, strikethrough and fenced code — plus footnotes, GitHub callouts, Mermaid diagrams, LaTeX math via KaTeX, and syntax highlighting for code. Anything KaTeX and Mermaid support, it supports.

Can I export to PDF?

Yes, through your browser's own print dialog, which keeps the text selectable rather than producing a screenshot. You can also export a self-contained HTML file or a PNG of the rendered page, with no watermarks and no page limits.

Is it really free? What is the catch?

It is free and MIT licensed, with no ads, no account and no paid tier. It is small enough to cost nothing to run, since there is no server. If you need something it does not do — a custom build, SSO, sync, an on-premise deployment — that is what we do for a living, and you can email us.

Can I self-host it or use it inside my company?

Yes. Download index.html and serve it from anywhere, or open it from disk. It needs no backend, no build step and no configuration. The MIT licence covers commercial use. For a branded or customised build, email support@kingsbridge-consultancy.com.
